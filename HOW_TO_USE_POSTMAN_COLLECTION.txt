POSTMAN COLLECTION - SIMPLE STEPS 🚀
==========================================

Bhai, bilkul simple hai! Bas yeh steps follow karo:

==========================================
STEP 1: POSTMAN MEIN IMPORT KARO
==========================================

1️⃣  Postman kholo

2️⃣  "Import" button pe click karo (top left corner mein)

3️⃣  "Choose Files" pe click karo

4️⃣  Is file ko select karo:
    📁 CampusRide_Postman_Collection.json
    
    Location: /Users/hardikmakwana/SpringProject/campusride/

5️⃣  "Import" button click karo

6️⃣  ✅ Done! Left sidebar mein "CampusRide API Collection" dikhai dega

==========================================
STEP 2: ENVIRONMENT SETUP (OPTIONAL)
==========================================

Environment banane se token management easy ho jata hai:

1️⃣  Left sidebar mein "Environments" pe click karo

2️⃣  "+" (plus icon) click karo

3️⃣  Environment name: "CampusRide Local"

4️⃣  Variables add karo:

    Variable          | Initial Value             | Current Value
    ------------------|---------------------------|---------------------------
    baseUrl           | http://localhost:8080     | http://localhost:8080
    token             | (khali rakhdo)            | (khali rakhdo)
    userId            | (khali rakhdo)            | (khali rakhdo)

5️⃣  "Save" button click karo

6️⃣  Top right corner se environment select karo: "CampusRide Local"

NOTE: token aur userId AUTO-FILL honge jab tum login karoge! 🎯

==========================================
STEP 3: FIRST API TEST - LOGIN
==========================================

Ab testing start karte hain:

1️⃣  Left sidebar mein "CampusRide API Collection" expand karo

2️⃣  "Authentication" folder expand karo

3️⃣  "Login" request pe click karo

4️⃣  Body tab check karo, yeh default data hai:
    {
      "email": "h@gmail.com",
      "password": "1234"
    }

5️⃣  "Send" button click karo 🚀

6️⃣  Response dekho:
    ✅ Status: 200 OK
    ✅ Body mein token aayega
    ✅ userId: 15
    ✅ Role: DRIVER

7️⃣  🎉 Token automatically save ho gaya environment mein!

==========================================
TESTING TIPS 💡
==========================================

✅ SEQUENTIAL TESTING:
   Folders ko top to bottom test karo

✅ AUTO TOKEN:
   Login karne ke baad token save ho jata hai
   Logout/new user test karne ke liye bas login again

✅ CHANGE DATA:
   Request bodies mein data modify kar sakte ho
   Example: source/destination change karo

✅ SAVE EXAMPLES:
   Good responses ko save karo:
   Right click → "Save as Example"

✅ CHECK STATUS:
   Response status codes check karo:
   - 200 OK = Success ✅
   - 201 Created = Resource created ✅
   - 401 Unauthorized = Token issue ❌
   - 403 Forbidden = Permission issue ❌
   - 404 Not Found = Resource not found ❌

==========================================
TROUBLESHOOTING 🔧
==========================================

Problem: Token not working (401 error)
Solution: Login again, token expire ho gaya hoga

Problem: 403 Forbidden
Solution: Wrong account, correct role se login karo
         (Admin APIs need admin login)

Problem: Environment variables not working
Solution: Top-right se environment select karo

Problem: Connection refused
Solution: Services running hai? Check karo:
         http://localhost:8761 (Eureka)

Problem: Can't find collection
Solution: Left sidebar mein "Collections" tab selected hai?
