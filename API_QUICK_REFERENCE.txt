==========================================
📝 COMMON REQUEST EXAMPLES
==========================================

Login:
------
POST /auth-service/api/auth/login
{
  "email": "h@gmail.com",
  "password": "1234"
}
Response: { "token": "...", "userId": 15, ... }

Create Ride:
------------
POST /ride-service/api/rides
Headers: Authorization: Bearer {{token}}
{
  "type": "OFFERING",
  "source": "Andheri",
  "destination": "Bandra",
  "departureTime": "2026-09-20T10:00:00",
  "availableSeats": 3,
  "pricePerSeat": 50.00
}

Search Rides:
-------------
GET /ride-service/api/rides/search?source=Andheri&destination=Bandra&type=OFFERING

Create Booking:
---------------
POST /booking-service/api/bookings
Headers: Authorization: Bearer {{token}}
{
  "rideId": 7,
  "seatsBooked": 1
}

Add Vehicle:
------------
POST /user-service/api/vehicles
Headers: Authorization: Bearer {{token}}
{
  "vehicleNumber": "GJ01AB1234",
  "vehicleType": "CAR",
  "vehicleModel": "Maruti Swift",
  "vehicleColor": "White",
  "seatingCapacity": 4
}

🔒 AUTHORIZATION
==========================================

Most APIs need token in header:
Authorization: Bearer <your-token>

Public APIs (No auth needed):
- POST /api/auth/register
- POST /api/auth/login
- GET  /api/rides/search
- GET  /api/rides/{id}
- GET  /api/vehicles/user/{userId}

==========================================
❗ COMMON ERRORS
==========================================

401 Unauthorized     → Login again, token expired
403 Forbidden        → Wrong role (need admin/driver)
404 Not Found        → Invalid ID or service down
500 Server Error     → Check backend logs
