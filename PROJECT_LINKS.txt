==========================================
API ENDPOINTS (VIA GATEWAY)
==========================================

Base URL: http://localhost:8080

AUTHENTICATION:
---------------
POST /auth-service/api/auth/register     - Register new user
POST /auth-service/api/auth/login        - Login
POST /auth-service/api/auth/forgot-password
POST /auth-service/api/auth/verify-otp
POST /auth-service/api/auth/reset-password

USER MANAGEMENT:
----------------
GET  /user-service/api/users/profile     - Get logged in user
PUT  /user-service/api/users/profile     - Update profile
GET  /user-service/api/users             - Get all users (Admin)
GET  /user-service/api/users/{id}        - Get user by ID
DEL  /user-service/api/users/{id}        - Delete user (Admin)

VEHICLE MANAGEMENT:
-------------------
POST /user-service/api/vehicles          - Add vehicle
GET  /user-service/api/vehicles/my       - Get my vehicles
GET  /user-service/api/vehicles/user/{userId} - Get user vehicles
PUT  /user-service/api/vehicles/{id}     - Update vehicle
DEL  /user-service/api/vehicles/{id}     - Delete vehicle

RIDE MANAGEMENT:
----------------
POST /ride-service/api/rides             - Create ride
GET  /ride-service/api/rides/search      - Search rides
GET  /ride-service/api/rides             - Get all rides
GET  /ride-service/api/rides/{id}        - Get ride by ID
GET  /ride-service/api/rides/my          - Get my rides
PUT  /ride-service/api/rides/{id}        - Update ride
DEL  /ride-service/api/rides/{id}        - Delete ride
POST /ride-service/api/rides/{id}/accept - Accept ride
POST /ride-service/api/rides/{id}/cancel - Cancel ride

BOOKING MANAGEMENT:
-------------------
POST /booking-service/api/bookings       - Create booking
GET  /booking-service/api/bookings/my    - Get my bookings
GET  /booking-service/api/bookings/{id}  - Get booking by ID
GET  /booking-service/api/bookings/ride/{rideId} - Get bookings by ride
PUT  /booking-service/api/bookings/{id}/cancel   - Cancel booking

ADMIN OPERATIONS:
-----------------
GET  /user-service/api/admin/driver-requests  - Pending drivers
PUT  /user-service/api/admin/approve-driver/{id}
PUT  /user-service/api/admin/reject-driver/{id}
GET  /user-service/api/admin/settings         - Get settings
PUT  /user-service/api/admin/settings         - Update settings

==========================================
TROUBLESHOOTING
==========================================

Backend Services Not Running?
  - Check: http://localhost:8761 (Eureka)
  - Check logs in /tmp/*.log files
  - Restart services manually

Frontend Not Starting?
  - Clear port: lsof -ti:5173 | xargs kill -9
  - cd frontend && npm run dev

Database Connection Error?
  - Check MySQL is running: mysql -u root
  - Check database exists: USE campusride;

Token Not Working (401)?
  - Login again, token may have expired
  - Token validity: 24 hours

Port Already in Use?
  - Kill process: lsof -ti:PORT | xargs kill -9
  - Example: lsof -ti:8080 | xargs kill -9
