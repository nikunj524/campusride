==========================================
ALL API ENDPOINTS
==========================================

AUTH SERVICE (Port 8081):
-------------------------
POST   /auth/register
POST   /auth/login
POST   /auth/forgot-password
POST   /auth/verify-reset-otp
POST   /auth/reset-password
GET    /auth/profile

USER SERVICE (Port 8082):
-------------------------
GET    /api/users
GET    /api/users/{id}
PUT    /api/users/{id}

VEHICLE SERVICE (Port 8082):
----------------------------
POST   /api/vehicles
GET    /api/vehicles/my
GET    /api/vehicles/user/{userId}
PUT    /api/vehicles/my
DELETE /api/vehicles/my

RIDE SERVICE (Port 8083):
-------------------------
POST   /api/rides
GET    /api/rides
GET    /api/rides/{id}
POST   /api/rides/search

BOOKING SERVICE (Port 8084):
----------------------------
POST   /api/bookings
GET    /api/bookings/{id}
GET    /api/bookings/passenger/{passengerId}
GET    /api/bookings/ride/{rideId}
PATCH  /api/bookings/{id}/status

ADMIN SERVICE (Port 8082):
--------------------------
GET    /api/admin/settings
PUT    /api/admin/settings

==========================================
COMMON ERRORS & SOLUTIONS
==========================================

Error: "First name is required"
Solution: Use firstName and lastName (not name)

Error: "Password must be between 8 and 72 characters"
Solution: Password minimum 8 characters

Error: 401 Unauthorized
Solution: Login again, token expired

Error: Connection refused
Solution: Check service is running on correct port

==========================================
VALIDATION RULES
==========================================

Password:
  - Min 8 characters
  - Max 72 characters

Phone Number:
  - 7-20 characters
  - Only numbers, +, (), -, space

Email:
  - Valid email format
  - Max 120 characters

Names:
  - Required
  - Max 50 characters each
