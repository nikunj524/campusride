POSTMAN MEIN KAISE RUN KARE?
==========================================

METHOD 1: Manual - Ek Ek Request
---------------------------------
1. Collection import karo (CampusRide_Postman_Collection.json)
2. Environment setup karo (baseUrl, token, userId)
3. Authentication folder kholo
4. "Login" request run karo
5. Token auto-save ho jayega
6. Baaki requests ek ek karke run karo

METHOD 2: Collection Runner (Batch)
------------------------------------
1. Collection pe right click
2. "Run collection" select karo
3. Order set karo:
   - First: Login
   - Then: Other requests
4. "Run CampusRide API Collection" click karo
5. Sab requests automatically run honge

METHOD 3: Newman (Command Line)
--------------------------------
1. Install newman:
   npm install -g newman

2. Run collection:
   newman run CampusRide_Postman_Collection.json

3. With environment:
   newman run CampusRide_Postman_Collection.json -e environment.json

ERROR CODES & SOLUTIONS
==========================================

200 OK              ✅ Success
201 Created         ✅ Resource created
204 No Content      ✅ Success, no data

400 Bad Request     ❌ Check request body format
401 Unauthorized    ❌ Login again, token expired
403 Forbidden       ❌ Use correct role (admin/driver)
404 Not Found       ❌ Invalid ID or endpoint
500 Server Error    ❌ Check backend logs

==========================================
QUICK TERMINAL TEST SCRIPT
==========================================

Sab commands ko ek saath run karne ke liye:

#!/bin/bash

# Health Check
echo "=== Health Check ==="
curl -s http://localhost:8761 | head -5
echo ""

# Login
echo "=== Login ==="
RESPONSE=$(curl -s -X POST http://localhost:8080/auth-service/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"h@gmail.com","password":"1234"}')
echo $RESPONSE | jq '.'

TOKEN=$(echo $RESPONSE | jq -r '.token')
echo "Token: ${TOKEN:0:20}..."
echo ""

# Get Profile
echo "=== Get Profile ==="
curl -s -X GET http://localhost:8080/user-service/api/users/profile \
  -H "Authorization: Bearer $TOKEN" | jq '.'
echo ""

# Search Rides
echo "=== Search Rides ==="
curl -s -X GET "http://localhost:8080/ride-service/api/rides/search" | jq '. | length'
echo " rides found"

echo ""
echo "✅ Basic tests completed!"

Save as: test_apis.sh
Run: chmod +x test_apis.sh && ./test_apis.sh
