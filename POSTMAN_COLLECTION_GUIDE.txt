==========================================
COMMON ERRORS & SOLUTIONS
==========================================

Error: 401 Unauthorized
------------------------
Solution: 
- Login phir se karo
- Token expire ho gaya hoga
- Environment me token set hai ki nahi check karo

Error: 403 Forbidden
--------------------
Solution:
- Tumhare role me permission nahi hai
- Admin endpoints ke liye admin login karo
- Driver endpoints ke liye driver login karo

Error: 404 Not Found
--------------------
Solution:
- API endpoint sahi hai ki nahi check karo
- ID valid hai ki nahi check karo
- Service running hai ki nahi check karo

Error: 500 Internal Server Error
---------------------------------
Solution:
- Backend logs check karo
- Database running hai ki nahi check karo
- Service crash to nahi hui check karo
